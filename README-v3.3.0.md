# Portal v3.3.0

## 本版內容

- 新增「學分檢核系統」入口與獨立權限同步。
- 修正「同步我的協作者」原本只同步服務紀錄的問題。
- 個別老師現在可依自己擁有的權限，同步服務紀錄、行政文書及學分檢核的小幫手。
- 小幫手被停用、刪除或取消個別系統權限後，再同步會撤銷對應授權。

## 安全上線順序

1. 先將行政文書包內新版 `firestore.rules` 發布到行政文書 Firebase。
2. 將行政文書 v1.0.2 覆蓋行政文書 GitHub Repository。
3. 將學分檢核包覆蓋學分檢核 GitHub Repository。
4. 到學分檢核 Firebase 發布 `firestore-bootstrap.rules`。
5. 將本入口包覆蓋入口 GitHub Repository。
6. 用最高管理員登入入口，到老師管理勾選「學分檢核系統」。
7. 按「同步學分檢核」並確認成功。
8. 立即回到學分檢核 Firebase，改發布正式 `firestore.rules`。
9. 再按一次「全部同步」，完成五套系統權限更新。

之後個別老師新增或修改小幫手，只需在「我的小幫手」按「同步我的協作者」。同步時會依老師與小幫手實際勾選的系統處理，不會修改其他老師的授權。

本版不修改公告、活動、服務紀錄的 Firebase 規則或正式資料；行政文書與學分檢核也不搬移既有業務資料。
