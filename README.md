## GitHub 更新方式

請將下列檔案上傳到 `must-resource-center` Repository 最外層，覆蓋同名檔案：

- index.html
- portal-config.js

其他檔案不需要更動。

若你的服務紀錄系統 Repository 網址不是 `must-service-record-system`，
只要修改 `portal-config.js` 中「資源教室服務紀錄系統」的 url 即可。
