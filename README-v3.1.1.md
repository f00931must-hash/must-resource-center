# Portal v3.1.1 更新說明

## 修正
- 個管老師可自行同步自己的協作者至服務紀錄，不必由系統管理員代為同步。
- 同步範圍只限登入老師名下的協作者，不會更動其他老師資料。
- 協作者若被停用、刪除或取消服務紀錄權限，再次同步時會一併移除服務紀錄授權。

## 必要設定
1. 覆蓋 Portal GitHub 專案檔案。
2. 將 `SERVICE-RECORD-firestore-v1.0.6.rules` 發布到服務紀錄 Firebase 的 Firestore Rules。
3. 覆蓋服務紀錄 v1.0.5 網站檔案。
4. 個管老師進入 Portal → 我的協作者 →「同步我的協作者」。
